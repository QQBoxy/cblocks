# 中文輸入法練習 Web 復刻版 (Chinese Input Method Practice Web)

這是一個基於 **Vue 3 + TypeScript + Vite** 開發的網頁遊戲，完美還原了 Windows 95/98 經典打字遊戲「中文輸入法練習」的懷舊視覺介面與遊玩體驗。

不論您是想重溫童年回憶，還是想練習倉頡、注音、嘸蝦米、拼音或其他中文輸入法，本專案都能為您提供原汁原味的打字練習體驗。

## 🎮 遊戲玩法與規則

1. **基本規則**：
   - 帶有中文字的方塊會從畫面上方徐徐落下。
   - 玩家需要切換至中文輸入法，輸入畫面上方塊對應的文字以將其消除。
2. **分數結算**：
   - 消除**正在落下**的方塊：獲得 `10 × 速度等級` 的分數。
   - 消除**已堆疊**的方塊：獲得 `15 × 速度等級` 的分數。
   - 輸入錯誤（字庫中無此字或輸入非畫面上文字）時，會播放錯誤音效。
3. **堆疊機制**：
   - 若方塊落地前未被消除，將會在該列底部堆疊起來。
   - 消除已堆疊的方塊後，該方塊上方的堆疊方塊會受重力引導自動下落。
4. **遊戲結束**：
   - 當任何一列的方塊堆疊到頂部（超出邊界）時，遊戲即宣告結束。

## ✨ 遊戲特色

- **經典 Win95 風格介面**：經典的灰色立體邊框、標題列、選單列與狀態列，細緻還原作業系統控制項。
- **純 Web Audio API 復刻音效**：使用瀏覽器音訊合成器（不需載入外部音檔）模擬懷舊的消去音、嗶嗶聲、錯誤音與遊戲結束慘叫聲。
- **五種速度等級**（由慢至快）：
  - 🐢 **烏龜** (Level 1) — 速度 15 px/s，生成間隔 4.5 秒
  - 🚲 **單車** (Level 2) — 速度 28 px/s，生成間隔 3.5 秒（預設）
  - 🚗 **汽車** (Level 3) — 速度 48 px/s，生成間隔 2.5 秒
  - ✈️ **飛機** (Level 4) — 速度 78 px/s，生成間隔 1.6 秒
  - 🚀 **火箭** (Level 5) — 速度 120 px/s，生成間隔 0.9 秒
- **三種字庫難度等級**（由輕至重）：
  - ⚖️ **1 KG**：常見字 (如：的、一、是、在、不...)
  - ⚖️ **10 KG**：次常用字與組合字 (如：倭、允、玄、抉、吾...)
  - ⚖️ **100 KG**：生僻字與高難度多筆劃字 (如：爨、鸞、龘、鱻...)
- **復刻選單快捷鍵**：支援經典視窗快捷鍵，在畫面上按下 `Alt + G` (開啟遊戲選單)、`Alt + O` (開啟選項選單)、`Alt + H` (開啟說明選單)。
- **設定儲存**：可手動切換聲音開關，以及清除高分紀錄。

## 🛠️ 開發與建置

### 1. 安裝依賴項目
```bash
npm install
```

### 2. 本地開發伺服器
執行以下指令啟動 Vite 開發伺服器：
```bash
npm run dev
```

### 3. 專案打包
將專案編譯並打包至 `dist` 目錄：
```bash
npm run build
```

### 4. 預覽打包後的網站
```bash
npm run preview
```
